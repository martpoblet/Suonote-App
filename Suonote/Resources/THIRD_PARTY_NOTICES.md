# Third-Party Notices

## GeneralUser GS SoundFont

This app uses **GeneralUser GS** as its primary SoundFont. GeneralUser GS is
created and maintained by S. Christian Collins and distributed under
**CC-BY 3.0**.

Official page:
http://www.schristiancollins.com/generaluser.php

Bundle path:
`Suonote/SoundFonts/Arachno/GeneralUser-GS.sf2`

## Arachno SoundFont (no longer used)

A Lite subset of Arachno SoundFont (created by Maxime Abbey / Arachnosoft) was
used by previous versions of the app. The file may still be present in the
repository but is no longer referenced by the Studio engine.

## Additional SoundFont packs (optional, registry-aware)

The Studio engine accepts dedicated SoundFonts per instrument family via
`SoundFontManager.swift`. When a family-specific pack is bundled it is used
in preference to GeneralUser GS. When new packs are added, record their
names, authors, and licenses below.

See `Suonote/SoundFonts/README.md` for the expected file paths.
